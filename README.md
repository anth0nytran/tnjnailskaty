# T&J Nails — Katy, TX

Production website for **T&J Nails** at `https://tjnailskaty.com`.

Built on **Next.js 15** (App Router) + **TypeScript** + **Tailwind v3** + **Resend** (transactional email).
Static pages are pre-rendered at build time, so search engines and AI crawlers see the full content — no JS execution required.

## Stack

- **Framework:** Next.js 15 (App Router, RSC)
- **Language:** TypeScript 5
- **Styling:** Tailwind 3 + Tailwind Typography
- **Fonts:** Fraunces (display) + Inter (sans), via `next/font`
- **Icons:** lucide-react
- **Forms:** Native HTML + Zod validation
- **Email:** Resend (`/api/quote`)
- **Hosting:** Vercel
- **Schema:** JSON-LD via `lib/schema.ts` (LocalBusiness/NailSalon, Service, FAQPage, Review, BreadcrumbList, Organization)

## Local development

```bash
# 1. Install (Node 20.18+ required for Next 15)
npm install

# 2. Configure env
cp .env.example .env.local
# fill in RESEND_API_KEY, RESEND_FROM, RESEND_TO

# 3. Run
npm run dev
# → http://localhost:3000
```

## Deploy

```bash
npm run build
npm run start          # local production preview
```

On Vercel: connect this repo. Framework preset = Next.js. Add the env variables from `.env.example` to the Vercel project. The www → apex 301 redirect is in `next.config.ts`.

## Environment variables

See `.env.example`. Required:

| Variable | Purpose |
|---|---|
| `RESEND_API_KEY` | Resend API key |
| `RESEND_FROM` | From address (must be on a verified Resend domain — e.g. `bookings@tjnailskaty.com`) |
| `RESEND_TO` | Where booking requests are delivered |
| `NEXT_PUBLIC_SITE_URL` | Canonical site URL (defaults to `https://tjnailskaty.com`) |

Optional: `RESEND_BCC`, `RESEND_REPLY_TO`.

## Post-launch SEO checklist

1. Set DNS so `www.tjnailskaty.com` and `tjnailskaty.com` both resolve.
2. In Vercel, set the production domain to `tjnailskaty.com` (apex). www → apex 301 is handled by `next.config.ts`.
3. In Google Search Console:
   - Add the property if not already present
   - Submit `https://tjnailskaty.com/sitemap.xml`
   - Use **URL Inspection → Request Indexing** for each new URL
4. In Bing Webmaster Tools: import from GSC.
5. Verify Rich Results in Google's [Rich Results Test](https://search.google.com/test/rich-results) — every page should show LocalBusiness, FAQPage where applicable, BreadcrumbList.
6. Update Google Business Profile to match the new site (URL, services, hours, photos).
7. Add the new sitemap URL to GBP.
